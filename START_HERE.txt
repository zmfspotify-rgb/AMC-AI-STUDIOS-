❓ TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

Problem: "Python is not recognized"
Solution: Install Python from python.org
         Check "Add Python to PATH" during installation

Problem: "Module not found" errors
Solution: Run: pip install python-dotenv pydantic flask flask-cors pytz python-dateutil

Problem: "Port 5000 already in use"
Solution: Close other programs using port 5000
         OR change port in .env file (FLASK_PORT=5001)

Problem: Browser doesn't open automatically
Solution: This is NORMAL! Just manually open: http://localhost:5000
